# Haunted Farm Site 🎃👻

A spooky website built with React and Tailwind CSS, inspired by Shocktoberfest.

## 🛠 Features

- Dark theme horror design
- Scary CTA and animations
- Ticketing section (commented out for now)
- Ready to expand with gallery, video, and more

## 🚀 Getting Started

```bash
npm install
npm run dev
```

To deploy on GitHub:
1. Create a new repo on GitHub
2. Run:
```bash
git init
git remote add origin YOUR_REPO_URL
git add .
git commit -m "Initial commit"
git push -u origin main
```
